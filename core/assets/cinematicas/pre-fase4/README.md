# Plano de contingência — antes da fase 4

Cinco assets independentes para a transição da fase 3 para o duelo com
Charlietron. Pixel art horizontal com falas em português. Gerados com
`image_gen` integrada; prompts completos em `prompts.md`.

## Ordem e roteiro

1. `01-ceo-e-assistente.png`
   - ASSISTENTE: Senhor, nossas máquinas foram derrotadas.
   - CEO: Então teremos que liberar o plano de contingência.
2. `02-plano-de-contingencia.png`
   - CEO: Envie o maior skatista que já existiu na humanidade.
   - ASSISTENTE: Sim, senhor. Iniciando o projeto Charlie Tron.
3. `03-construcao-charlietron.png`
   - No laboratório secreto, o projeto proibido ganha forma.
   - A construção de Charlie Tron começou.
4. `04-skate-e-montagem-final.png`
   - Precisão de máquina. Equilíbrio absoluto.
   - Cada peça foi feita para dominar as pistas.
5. `05-charlietron-ativado.png`
   - ASSISTENTE: Charlie Tron está pronto, senhor.
   - CEO: Então mande-o para as ruas.

O CEO usa cabelo prateado, terno preto e gravata vinho; o assistente tem
cabelo preto, óculos redondos, terno azul e tablet. Charlietron segue a versão
robótica da cinemática final: boné preto e cinza, camiseta de caveira, corrente,
bermuda vinho, membros metálicos articulados e detalhes âmbar.

São quadros completos, não sprites de personagem. Usar filtro `Nearest` e
preservar a proporção inteira, incluindo as legendas. A reprodução no jogo
ainda não está implementada, assim como nas demais pastas de cinemáticas.
